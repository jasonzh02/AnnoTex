# AnnoTex v0.1.0

AnnoTex v0.1.0 is the first early release for editable text and MathJax-backed
math annotations on PDFs.

## Highlights

- Add editable annotations to PDFs.
- Render plain text, math-only input wrapped in `$$...$$`, and mixed text/math
  using inline `$...$`.
- Preserve editable source, rendered font size, rendered color, and layout
  metadata across save and reopen.
- Copy, cut, paste, delete, undo, and redo annotation boxes.
- Paste copied annotations with collision-aware placement.
- Export visible PDF annotation appearances for external PDF readers.

## Install

1. Download `AnnoTex-v0.1.0.dmg`.
2. Open the DMG.
3. Drag `AnnoTex.app` to Applications.
4. Launch AnnoTex and open a PDF.

## Known Limitations

- This is an early `v0.1.0` release.
- Multi-tab PDF viewing is not implemented yet.
- Native PDF reader tools such as PDF text selection and highlighting are still
  future roadmap items.
- Save/export choices are still simple; flattened export is planned separately.
- The app currently targets macOS 15.0 or newer.
